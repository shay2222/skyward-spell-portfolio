# The Skyward Spell: project page

The project page for **The Skyward Spell**, a storybook adventure by Shane Singh, written in C++ and compiled to WebAssembly.

- **Project page:** https://shay2222.github.io/skyward-spell-portfolio/
- **Play the game:** https://shay2222.github.io/skyward-spell/
- **Game source:** https://github.com/shay2222/skyward-spell

The page is a single `index.html` with its screenshots embedded, served by GitHub Pages from the root of this repository.
